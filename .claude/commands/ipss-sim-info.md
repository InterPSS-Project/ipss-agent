Show the network information of the current InterPSS simulation case — the case selected in the InterPSS tab — or of a named case.

Read and follow `.agents/skills/ipss-sim-info/SKILL.md` (canonical). That skill defines the tool call, the case-resolution order, how to read the result, and the fallbacks for agents without the tool.

**Examples:**

```
/ipss-sim-info
/ipss-sim-info data/ieee/Ieee118Bus/ieee118.ieee
/ipss-sim-info IEEE 14-bus
```
